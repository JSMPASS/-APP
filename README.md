# 习惯打卡

本项目使用 Python 实现，是一个纯离线、单用户的 Windows 桌面打卡应用，用于公考行测 / 申论的每日计划与打卡记录，支持题库（离线 OCR）、错题反思、总体进度，并可一键把打卡情况（含题目/解析/对错/反思）整理成 Word / PDF 报告，在长期坚持中养成良好的学习习惯。

## 功能一览

- **每日计划**：按细分知识点制定计划、为每项设置到分钟的提醒时间；支持复制昨日计划、日历选日；科目目录支持三级结构与长按拖动调整顺序/层级。
- **打卡**：文字总结 + 多图上传；打卡成功后随机激励语；提交后可自动识别图片中的题目并收录进题库，**一张图里有多道题时会按题号/年份自动拆成多题**（可取消勾选关闭），也可一键手动收录。
- **题库**：上传题目图片，离线 OCR 识别预填题目/解析，自动编号（Q0001…），按大/小知识点分类，标记对错（正确-完全理解/蒙对；错误-读题粗心/计算粗心/知识点了解不全）。
- **题型思维导图**：每科一张导图，预置知识点自动导入并关联题目统计；三种布局（环形放射/两翼对称/右向逻辑图）；分层贝塞尔曲线；拖拽改层级、同级重排、自由主题与对齐辅助线；双击内联编辑、键盘导航（Tab/Enter/方向键）；折叠不重排；一键导出 Markdown。
- **错题反思**：按「我的做题思路 / 正确的做题思路 / 反思改进」三个维度逐题反思。
- **总体进度**：顶部展示完成计划总数/已完成数量/总体完成率与进度条；另有可自定义的指标窗口。
- **备考进度（90 天计划）**：一键按《90天学习计划.md》的每周执行模板铺排 90 天「3 主 + 1 辅」任务（含作息提醒、周日大作文、周一/三/五数量插空、阶段标记）；导航页展示三阶段、13 周逐周重点、检查点、90 天打卡热力图与每日作息模板。铺排完成后自动跳转到「今日」页进入打卡；点击热力图任意一天可跳转该天计划，「去打卡」一键回到今日打卡。
- **主/辅任务与连续打卡**：打卡项区分主任务/辅助任务；今日页与热力图统计连续打卡天数；显示「完成 80% 即合格」的合格线提示（不补账、不断档）。
- **每周复盘**：按周记录复盘心得与下周重点（自动统计本周完成率与新增错题）。
- **检查点与专注提醒**：第 10/20/30/45/60/75/90 天自动弹出检查点提醒；打卡计时达到设定专注时长（默认 45 分钟）后弹休息提醒，并实时显示今日累计学习时长。
- **深色模式**：设置中可切换深色/浅色主题（重启后生效）。
- **数据备份**：每天打开应用自动备份一次 `app.db`（保留最近 14 份，目录 `data/backups`），设置中可手动立即备份。
- **报告导出**：Word 与 PDF 双格式，包含完成统计、打卡详情（含学习时长）、题目与解析、错题反思、未完成项。
- **系统托盘**：点击窗口 X 可选择「退出」或「最小化到托盘」，点击最小化按钮也会直接最小化到托盘；最小化后可从系统托盘恢复或退出（依赖 `pystray`）。
- **提醒**：App 运行时到点置顶提醒 + 提示音（可开关）。

## 项目结构

```
习惯打卡/
├── src/habit_checkin/      # 应用源码包
│   ├── app.py              # 入口逻辑（数据目录、图标）
│   ├── db.py               # SQLite 数据层
│   ├── ui/                 # 界面（主窗口、计划、打卡、题库、反思、进度、设置、日历、主题）
│   ├── services/           # 提醒、OCR、Word/PDF 导出、激励语、系统通知
│   └── resources/          # 图标等资源
├── tests/                  # 单元测试
├── assets/icon.ico         # 应用/打包图标
├── data/                   # 运行时数据（开发态；打包态在 exe 同级）
├── build.py / build.bat    # 打包脚本
├── pyproject.toml          # 工程元数据与依赖
├── requirements.txt        # 依赖清单
└── start.bat               # 开发启动（双击）
```

## 环境与依赖

- Python 3.10+（自带 tkinter）。项目优先使用仓库内 `venv\Scripts\python.exe`，未创建虚拟环境时回退到系统 `python.exe`。
- 若本机 Python 缺少可用的 Tcl/Tk 脚本目录，可把 `tcl8.6`、`tk8.6` 放到仓库根目录 `runtime\tcl` 下；启动与打包时应用会自动设置 `TCL_LIBRARY` / `TK_LIBRARY`。
- 依赖：`python-docx`、`Pillow`、`reportlab`、`numpy`（离线可用，无需联网；`numpy` 用于 OCR 图片预处理与图形去背景）。
  - 系统托盘依赖：`pystray`（用于最小化到托盘）。

## 开发运行

```
# 安装依赖（首次）
python -m pip install -r requirements.txt
# 可选：可编辑安装
python -m pip install -e .

# 启动（开发态）
set PYTHONPATH=src
python -m habit_checkin
```

或直接双击 `start.bat`（使用 pythonw 无黑窗启动）。

## 测试

```
python -m unittest discover -s tests -v
```

## 构建打包（正式 App）

1. 双击 `build.bat`，或手动执行：
   ```
   python -m pip install pyinstaller
   python build.py
   ```
2. 输出 `dist/习惯打卡/`（目录版，含 `习惯打卡.exe`），并在**桌面生成「习惯打卡」快捷方式**。
3. 构建前会自动**全新初始化** data（清空开发态数据）。

> 注意：安装 PyInstaller 需要联网。若网络不可用，项目仍可正常以源码方式运行，待有网后再打包。

## 数据存放与备份

- 开发态：`data/`（仓库根目录，`app.db` + `images/` + `app.log`）。
- 打包态：exe 同级 `data/` 目录，随 `dist/习惯打卡/` 整个拷贝即可迁移备份。
- 首次运行自动建库并写入预置科目与内置指标。

## 说明与限制

- 提醒仅在 App 运行时生效；关闭 App 后不提醒。
- 深色模式在「设置 → 通用设置」切换，重启应用后生效。
- Windows 系统通知为尽力而为（未注册应用 ID 时可能不显示，自动降级为 App 内提醒）。
- OCR 使用 Windows 自带 WinRT OCR（zh-Hans），识别结果仅作预填，由用户确认/编辑；无中文 OCR 引擎时自动回退手动录入。
- 图片入库与报告导出均会压缩到长边 ≤1600px（GIF 保持原样），保证存储与文档体积合理。
